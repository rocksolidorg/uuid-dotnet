# uuid-dotnet
A simple UUID library for dotnet

## Description

This library provides a high-quality, standards-aware implementation of GUID/UUID generation for .NET applications. It
is designed for developers who require deterministic behavior, predictable sorting characteristics, and platform-neutral
identifiers across distributed systems, storage engines, and event-driven architectures.

Unlike System.Guid, which only exposes random (v4) identifiers and does not distinguish between UUID variants or
generation strategies, this library offers an explicit, well-structured API for multiple UUID versions and usage
scenarios.

The library supports:

- v1
- v3
- v4
- v5
- v6
- v7
- v8
